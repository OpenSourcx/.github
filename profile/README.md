## Papercliped

Run your [Paperclip](https://github.com/paperclipai/paperclip) from Claude, ChatGPT, Codex or any MCP app. Check on agents, assign work, decide approvals and get status, cost and activity reports in plain language, without opening the dashboard.

| **Connect** | Add `https://mcp.papercliped.co/mcp` as a connector in your AI app |
| **Control** | Read only or Full control, plus per-agent rules in the control room |
| **Self-host** | Run the bridge yourself, or locally with `npx papercliped` |
